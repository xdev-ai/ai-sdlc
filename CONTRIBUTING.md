# Contributing to AI-SDLC

AI-SDLC follows the shared **xDev AI** contribution process.

Please refer to the [xDev AI Contributing Guide](https://github.com/xdev-ai/ai.xdev.asia/blob/main/CONTRIBUTING.md).

### AI-SDLC-specific notes

- Every change in `spec-kit/` must include an update to `check-kinds.md` when it introduces a new check kind.
- Prefer keeping engine logic in Rust crates and rules in YAML files.
