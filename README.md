# AI-SDLC — Governed AI-Assisted Delivery

[![Website](https://img.shields.io/website?url=https%3A%2F%2Fai.xdev.asia%2Fai-sdlc&label=ai.xdev.asia/ai-sdlc)](https://ai.xdev.asia/ai-sdlc)
[![Organization](https://img.shields.io/badge/Org-xDev%20AI-123450)](https://github.com/xdev-ai)

AI-SDLC là sản phẩm đầu tiên của **xDev AI**: một lớp governance cho AI-assisted software delivery với versioned policy, deterministic validation và evidence có thể truy vết.

## Thành phần cốt lõi

- **Spec Kit**: Tập hợp các luật (policy-as-data) được version hóa.
- **Engine**: Bộ máy kiểm tra deterministic viết bằng Rust.
- **Evidence Trace**: Hệ thống liên kết bằng chứng từ requirement đến release.
